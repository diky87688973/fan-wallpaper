# 桌面壁纸轮播 —— 遮盖层方案

## 目标

指定一个素材目录，按设定间隔自动更换桌面背景，图片与视频都铺满主屏、不留黑边。
程序关闭后桌面恢复原样，不留下任何痕迹。

## 约束

```text
1. 不改变用户的壁纸设置
   程序不写入新的壁纸路径，也不修改 WallPaper 注册表值。
   桌面内容由挂在壁纸层的遮盖窗口提供，关掉窗口后原壁纸自然回来。
   唯一触碰系统壁纸接口的是退出后的重绘，只把读到的原值交回系统。

2. 退出后触发重绘
   遮盖窗口销毁时 Explorer 不会自己重画，桌面会停在最后一帧或纯黑。
   InvalidateRect、WM_SETTINGCHANGE、SHChangeNotify 实测均无效，
   只有把当前壁纸路径原样交回系统才有效，实现见 backend.repaint_desktop。

3. 不自己渲染像素
   解码、缩放、色彩转换、宽高比裁切全部交给 WebView2 内核。
   不在自己的代码里做 YUV 转换、逐像素拷贝或图片预渲染，页面固定 object-fit: cover。

4. 先加载后切换
   新素材先加载到就绪，再让旧元素淡出、新元素淡入。
   禁止「先删掉旧的，再等新的加载」——那中间必然整屏黑。

5. 启动先清理残留
   上一次没退干净的遮盖窗口，启动时先收掉，避免叠在桌面层上。
```

## 架构

```text
主控进程（Python + tkinter）
  ├─ 界面：目录、间隔、顺序、包含视频、静音、开始/停止/立即换
  ├─ 托盘：显示窗口、立即换一张、开始/停止、包含视频、声音、退出
  ├─ 调度器：到点现扫目录，选下一个素材
  └─ WallpaperBackend：起停显示进程，下发命令，接收事件
        │
        │ stdin/stdout，每行一条 JSON
        ▼
显示进程（Python + pywebview / WebView2）
  └─ 无边框全屏窗口，SetParent 到 WorkerW
       └─ 页面：单个 media 元素，object-fit: cover
            ├─ 静态素材 → <img>
            └─ 动态素材 → <video autoplay muted>
```

## 组件

```text
wallpaper_app.py            装配：界面、托盘、调度、后端接线
wallpaper/config.py         配置读写、校验与原子落盘
wallpaper/scheduler.py      轮播节奏，到点现扫目录
wallpaper/screen.py         进程 DPI 感知
wallpaper/media.py          按扩展名列目录，不读文件内容
wallpaper/desktop.py        壁纸层 WorkerW 定位，主控与显示进程共用
wallpaper/ui.py             界面
wallpaper/tray.py           托盘图标与菜单
wallpaper/wallview.py       显示进程：WebView2 窗口 + 页面 + 挂载
wallpaper/backend.py        起停显示进程、命令与事件协议
```

## 数据流

```text
切图
  调度器 tick
    → 现扫目录（不缓存列表）
    → 按顺序/随机选下一个
    → 发 {"cmd":"show","kind":"image|video","path":...,"muted":true|false}
    → 显示进程：创建元素 → 等 loadeddata/load → 淡入新元素 → 旧元素淡出并移除
    → 回报 {"evt":"loaded"} 或 {"evt":"load_error"}

视频播完
  → 页面 onended
  → 回报 {"evt":"ended"}
  → 主控解除调度暂停，立即切下一张
  → 十分钟内未收到 ended 视为播放已终止，调度器自行解除暂停

退出
  → 停调度（不再有新指令）
  → 发 {"cmd":"quit"}
  → 显示进程销毁窗口
  → repaint_desktop 把当前壁纸路径原样交回系统，触发桌面重绘
```

## 素材供给

WebView2 禁止页面直接加载 `file://` 资源，所以由显示进程起一个只读回环 HTTP 服务：

```text
127.0.0.1:随机端口  →  素材所在目录
URL = http://127.0.0.1:<port>/<文件名>
目录变化时重建服务
```

## 手工验收清单

以下项目需要在 Windows 桌面上人工执行，尚未自动化。

```text
切图无黑屏
  连续切换 3 次，切换期间不应出现接近全黑的帧

退出无残留
  壁纸层 WorkerW 子窗口数为 0
  WallPaper 注册表值与启动前完全一致
  任务管理器里没有残留的显示进程

视频播完自动切
  播一段 30 秒视频，31 秒内当前素材应已改变

启动清理残留
  人为留一个残留窗口，再启动，残留应被关掉

缺依赖提示
  只装部分依赖后启动，应弹出缺依赖消息框而不是无反应

配置损坏提示
  把 config.json 改成非法 JSON 后启动，界面日志应出现带文件路径的告警
```

## 明确不做

```text
- 壁纸快照、还原、启动恢复
- 图片预渲染成屏幕尺寸
- 自己写 D3D / YUV 着色器 / 纹理上传
- 视频解码
- 多显示器
- 开机自启
- contain 铺满方式
```
