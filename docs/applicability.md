# 适用性申报

按 `production-standards` 0.5 登记本项目不适用的准则。编号取自该标准与 `audit-procedure` 检查矩阵。

| 准则 | 申报 | 原因 | 风险由谁承担 |
|---|---|---|---|
| `S8` | 不适用 | 本地单机桌面程序，无对外服务、无路由、无鉴权边界 | 无（不存在跨信任域调用） |
| `V3` | 不适用 | 没有部署脚本，程序以 `start.bat` 直接启动 | 无 |
| `V4` | 不适用 | 不做服务部署与数据库迁移，回滚等价物是版本降级；配置只前滚 | 维护者（降级时未知键被忽略，见 `P4`） |
| `P4` | 仅前滚 | `config.json` 新增字段对旧版不可见，旧版忽略未知键；不提供迁移 | 维护者 |
| `O2` | 不适用 | GUI 程序无进程健康检查；诊断面是界面日志与托盘状态 | 维护者 |
| `X1` | 部分适用 | 单元层已覆盖配置、素材枚举、调度器；集成与端到端层需真实 Windows 桌面与 WebView2 | 维护者（见 `docs/方案.md` 手工验收清单） |
| `X5` | 已接入 | 覆盖率由 CI 产出；`omit` 三条均带注释：`ui.py` 需 Tk 窗口、`wallview.py` 需 WebView2 与桌面层、`wallpaper_app.py` 构造即起窗口与托盘，三者无法在单元层实例化；其余模块全部纳入并逐条设下限 | — |
| `X6` | 已接入 | 全局下限 80%，另有 `scripts/check_coverage.py` 逐模块比对下限，未登记文件直接失败 | — |
| `K4` | 未接入 | 唯一的并发点是调度线程与三个 `queue.Queue`，未引入竞态检测工装 | 维护者 |
| `MUST` 类安全规则 `BLE001` `S110` | 未启用 | 外部回调与 Win32 调用需宽捕获；现有 21 处均在调用点写明理由 | 维护者 |

## 已知未纳入门禁的项

| 项 | 状态 | 说明 |
|---|---|---|
| 窗口挂载与画面表现 | 手工验收 | 需真实桌面，见 `docs/方案.md` 手工验收清单 |
| `.example` 与解析器键集合比对 | 手工 | `tests/test_config.py` 锁定 `Config` 字段，`config.example.json` 依赖人工同步 |
| 生成文档漂移 | 不适用 | 项目没有由脚本生成的文档 |
